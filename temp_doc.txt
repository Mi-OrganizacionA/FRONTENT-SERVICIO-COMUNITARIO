💻 STACK TECNOLÓGICO Y HERRAMIENTAS UTILIZADAS
La plataforma comunal ha sido construida utilizando una arquitectura moderna, escalable y sin dependencias pesadas innecesarias, asegurando un mantenimiento ágil a futuro.
Frontend (Interfaz de Usuario Ciudadana e Interna): Desarrollado estrictamente con HTML5, CSS3 (Vanilla) y JavaScript puro (ES6+ sin frameworks como React o Angular), garantizando máxima ligereza en la carga. El consumo de datos se hace mediante la API Fetch nativa.
Backend (Servidor RESTful y Lógica de Negocio): Arquitectura MVC operando sobre Node.js utilizando Express.js como framework de enrutamiento.
Base de Datos y ORM: Sistema híbrido. Se utiliza SQLite para el entorno de desarrollo ágil de los programadores, y PostgreSQL como motor robusto de bases de datos relacionales en el entorno de producción. Toda la interacción se maneja mediante Sequelize ORM.
Seguridad y Criptografía: Implementación estricta de JSON Web Tokens (JWT) para manejo de sesiones sin estado, integración con Firebase Auth, y encriptación hash de contraseñas de un solo sentido utilizando bcryptjs.
Despliegue y Hosting (Cloud): Ecosistema de alta disponibilidad. El Frontend estático es servido a través de Firebase Hosting (sicag-oficial.web.app) y la API Backend opera desde Render (sicag-api.onrender.com).
Herramientas de Validación y Control: Joi para la validación estricta de esquemas de datos entrantes en la API (evitando inyecciones en los formularios de censo), y Git/GitHub para el control de versiones y trabajo colaborativo del equipo desarrollador.
